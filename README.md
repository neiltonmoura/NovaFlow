## 💻 Sobre o projeto

<!-- EXPLICA O MOTIVO DO PROJETO -->
Nova Flow – Landing Page Responsiva com Tailwind CSS

Bem-vindo ao repositório da Nova Flow, uma interface moderna e responsiva criada para apresentar uma solução de gestão empresarial inteligente. Esta landing page foi desenvolvida utilizando HTML5 e Tailwind CSS, focando em desempenho, responsividade e estética moderna.
